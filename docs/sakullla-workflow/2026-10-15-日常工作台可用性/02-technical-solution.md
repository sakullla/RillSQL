# Technical Solution

覆盖 R1–R7。R8–R12 保持现状：不新增引擎、ER、结构对比、生成式 AI、整库备份还原或执行前语义分析。默认的“执行全文”快捷键不改。

## ADR 1 字段补全走单表 describe

目录对象没有字段。列和主键已经由 `src-tauri/src/grid/live.rs` 的 `describe` 按一张表读取。

补全仍在查询编辑器。表和视图名继续来自当前执行目标的目录。字段在补全时按这一张表调用现有 describe，并缓存在该连接和数据库上。点号后只描述点号前那个已读到的对象。未加限定的补全包含已经缓存的字段、关键字和对象名。describe 失败、未连接或对象尚未读到时，沿用现在的说明，不生成猜测字段名。不解析别名、联接和子查询。

## ADR 2 格式化只改本地文本

`src/query/split.ts` 已经识别引号、注释和 dollar-quote。格式化复用这套闭合判断，不新增 SQL 解析库，也不连接数据库。

编辑器命令可以格式化选区或全文。引号、注释或 dollar-quote 未闭合时，原文本不变，并显示原因。标识符、字符串、数值和注释文本保持不变；关键字按现有关键字表统一为大写，并整理缩进与换行。只格式化选区时，选区外的文本不变。

## ADR 3 执行计划是一条语句的 EXPLAIN

计划不跟随“无选区就执行全文”。无选区时使用光标所在语句，有选区时使用选区；这是需求 R3 写明的规则。选区或当前语句为空，或拆成多条有内容的语句时，不发起执行并显示原因。

按引擎加前缀，且不含 `ANALYZE`：PostgreSQL 和 MySQL、MariaDB 用 `EXPLAIN`，SQLite 用 `EXPLAIN QUERY PLAN`。结果沿现有查询执行返回，第一关键字保持 `EXPLAIN`，因此不按写入语句分类，也不套结果行数上限。展示为只读文本或表格，不进入查询结果编辑。引擎报错时沿用现有错误展示。

## ADR 4 查询结果复用表暂存，但先证明单表

`src/query/rows.ts` 现在把结果行标成不可定位。只有同时满足以下条件才允许改单元格或标记删除：语句是一条 `SELECT`；能确定只涉及一张基表；没有 `JOIN`、`UNION`、`GROUP`、`DISTINCT` 或聚合；describe 证明它是表而不是视图；主键列都在结果中；`src/grid/data.ts` 的 `locatorFrom` 能唯一标出该行。

修改和删除走现有预览与 `grid_commit`。查询结果不提供新增行。无法证明时保持只读，并显示与视图或缺少主键相同类别的原因。同名表出现在多个模式且 SQL 没有写出模式时，也保持只读。

提交仍是逐条写入。前面已经成功的语句保持已写入；失败行和尚未执行的暂存继续显示错误，不能标成已成功。不为查询结果另加回滚事务，避免改动表数据已经存在的提交语义。

## ADR 5 导入在确认后逐行插入已有表

导入选择当前连接上的一张已有表。CSV 使用现有 CSV 解析。JSON 必须是对象数组，否则确认前就拒绝。使用者看到字段对应、将写入的行和行数；行预览复用现有虚拟行窗口。必填列没有对应字段时不能开始。取消不写入。

确认后每一行按现有插入提交。某一行失败时显示该行原因，整体不显示为全部成功。不从文件建表，不读取表上尚未提交的修改。

## ADR 6 JSON 与 INSERT 沿用 CSV 的两条写出路径

已读取的行仍在客户端生成内容，并走现有原生暂存写入：失败不替换已有目标文件，取消保存不产生任务。全量导出仍在服务端流式写出，不把全部行拉进界面。表的全量按当前筛选和排序重读；查询的全量仍经过 `select_export_gate`，只接受一条 `SELECT`，并保留重新执行前的确认。

新增格式是 JSON 对象数组和仅含这些行的 `INSERT`。空值保持为空值。标识符引用沿用 `src-tauri/src/grid/sql.rs` 的引擎规则。截断的已读导出继续使用部分结果名称。未提交修改不进入文件。说明文字继续表明这不是数据库备份。

## ADR 7 保存查询不写入执行历史

`query_history` 记录一次执行的状态和时间。保存查询是命名文本，使用同一本地库中的新表，单独的读取、保存、重命名和删除命令。

`saved_queries` 在 `src-tauri/src/query/history.rs` 的 `HistoryStore::open` 创建 `query_history` 之后建立。`HistoryStore` 向同模块暴露连接池，供保存查询读写。建表和连接池访问都落在这个打开路径上，不挪到其它文件。

打开时复用历史的不执行计划：连接仍在目录中就恢复目标，连接已删除就只载入 SQL 并要求重选目标。删除前可以取消。历史的列表、载入和清空不变，打开保存查询不新增成功历史。

## 未知

保存查询不分组。单次导入不设行数上限；预览必须能看到将写入的行和总行数。各引擎计划列不同，只要求可读且不改数据。

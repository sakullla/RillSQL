- **源码级**：状态判定（`probing` / `inventory.probed` / `inventory.connected`）与危险操作的判定（`AdminSession::preview_dangerous`）
  由 `cargo test` 里的模型用例钉住。
- **headless 布局级**：GPUI 无头测试窗口（1360 / 900 / 640 宽 × 900 高，浅色/深色 × 紧凑/标准）里读出的
  元素存在性、可见性与边界，证明三态真的换成了底座组件、空态说明与操作入口都在窗口内。
- **未取得：原生像素截图。** 本任务运行环境没有原生窗口与截屏通道，没有生成
  「浅色/深色 × 紧凑/标准 × 1360/900/640」的 PNG。按执行计划，这类证据由 Delivery Owner 在最终集成
  candidate 上取得；本目录不用历史截图替代，也不把 headless 布局结论当成原生像素证据。该缺口在
  `test-receipts.md` 的「未执行 / 不计作通过」一节同样列出。

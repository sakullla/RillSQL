## 结论摘要

- 每条语句现在同时携带「用户写的原文」与「驱动实际发出的语句」，以及自动改写的种类、插入点与被插入文本；只有真的改写过才有改写来源。
- 自动追加 LIMIT 造成的语法错误：消息页与语句面板各显示一次「执行前被自动改写（追加 LIMIT 1001）」与实际执行的语句；结果头只留「失败」+ 定位按钮。
- 手写 LIMIT 的报错按原文展示，不带任何改写说明。
- 定位仍以草稿原文为准：改写位置映射回原语句边界（`rewrite_anchor`），驱动没给偏移时错误标记是整条语句，不会出现假的精确位置。

# 2026-11-16 UI/UX 实用性打磨

方法：在原生应用里连真实的 Docker 库（PostgreSQL / MySQL / MariaDB / SQL Server）照日常流程操作，记录卡点再修。
每项行为改动都有对应 Rust 测试；截图来自原生应用（`ui-ux-2026-11-16/`，1942×1241，深色，中文）。

## 修复与改进

| # | 问题 | 处理 |
|---|---|---|
| 1 | PostgreSQL 等驱动报错只显示 “db error”，看不到真正原因 | 新增 `error_text`：沿 `source()` 展开错误链，PG 附带 DETAIL/HINT，去掉重复片段；catalog、compare、ddl、diagram、grid、query、migrate、dump 统一使用 |
| 2 | 大纲里单条语句的运行按钮和双击没有反应 | 外壳 `query_command()` 漏了 `outline-run:` / `outline:`；已补，回归测试在缺修复时失败 |
| 3 | 错误只能定位不能复制 | 错误条加 “复制错误” |
| 4 | 目标选择器：没有连接时一片空白；绑定的连接被删除后无提示 | 空态 + “新建连接”；缺失目标显示警示描边、删除线和警示图标，删除后立即从选择器移除；弹层高度随内容 |
| 5 | 对已删除的目标点 “运行” 只报 “连接没有打开” | 执行前拦下，说明原因并直接打开选择器；换目标后提示消失；状态栏点目标同样打开选择器 |
| 6 | 状态栏不反映目标缺失 | 警示色 + 图标 |
| 7 | 连接表单 | 粘贴 URL 自动解析；解析错误标在 URL 字段；名称占位显示默认名 |
| 8 | 连接失败原因只闪一下 | 每条连接记住失败原因：资源树出现 “连接失败” 行（原因 + 重试 / 编辑），状态点提示和启动页重试条也带原因 |
| 9 | 自签名证书失败没有出路 | 提示设置 CA 文件或改用 “加密”（不核对证书）；文案统一为 “核对证书” |
| 10 | 连接右键菜单首项固定为 “连接” | 已连接时为 “断开连接” |
| 11 | 删除连接确认不说删哪条 | 标题带连接名，正文说明受影响的已打开标签数 |
| 12 | 深色主题编辑器行号栏近乎纯黑，和正文脱节 | 行号栏与正文使用编辑器配色的同一底色（各配色方案均验证） |
| 13 | 设置里编辑器配色要下拉 | 改为五段分段控件 |
| 14 | 小细节 | 树节点箭头去掉过时提示；对象路径不再出现悬空 “·”；命令面板命令行不再重复标 “命令”；“数据库管理” 图标与标签页统一为 Gauge；主题切换提示不再过时 |
| 15 | 表格单元格文字顶对齐，双击编辑时文字下跳 | 单元格内容垂直居中，与原位编辑框对齐 |

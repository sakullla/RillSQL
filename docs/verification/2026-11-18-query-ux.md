# 查询页体验打磨

基线：`c250b90`（v0.2.43）。范围：查询工作项：工具条、SQL 编辑器、结果头和结果区。

**取证方式**：Linux 下用 Xvfb 跑原生调试版，连接 Docker 里的 PostgreSQL 16 夹具，用 xdotool 真实点击和按键，`import` 截图。
截图在 `query-ux-2026-11-18/`。问题先在原生窗口里看到，再读代码确认。

## 修复与改进

| # | 问题 | 处理 |
|---|---|---|
| 1 | **执行多条语句时，还没执行到的语句被画成“成功”**：结果区写着未翻译的 `pending`，配绿色对勾；页签上全是绿点；结果头写“0 行”（`00-before-pending-as-success.png`） | 执行中，第一条还没有结果的语句显示转圈和“正在执行”，后面的显示时钟图标和“等待执行”；页签点分别是强调色和灰色；没结果的语句不报行数。已经发布过行的语句照常显示结果（`03`、`04`） |
| 2 | **工具条上“运行”和“执行当前语句”在没有选区时做的是同一件事**，而“执行脚本”藏在“更多”菜单里，也没有快捷键 | 第二个按钮改成“运行全部”（Ctrl/⌘+Alt+Enter，新快捷键，也进了快捷键帮助、应用菜单和“更多”菜单）。“执行当前语句”仍在“更多”菜单，快捷键 Ctrl/⌘+Shift+Enter 不变 |
| 3 | 看不出“运行”这次会跑什么：有选区只跑选区，没有选区跑光标所在语句 | 有选区时主按钮写“运行选中”，提示也跟着变；选区消失时变回“运行”（`02`） |
| 4 | 长查询执行时只有一个转圈，不知道已经跑了多久 | 结果头和首次执行的加载态写“正在执行 3.4 s”，每 200ms 更新一次，一分钟后按“2m 05s”显示；所有执行结束后计时循环自动停止 |
| 5 | 编辑器没有光标位置和选区大小 | 编辑器底部加一行低对比度状态行：“行 n，列 m”，有选区时加“已选 x 个字符，y 行”。列按字符数计，中文不按字节算 |
| 6 | 空结果页只有一个孤零零的 `Ctrl+Enter` 键帽 | 列出三种执行方式和对应快捷键（运行选中或当前语句 / 只运行当前语句 / 运行全部） |
| 7 | 停止按钮没有快捷键提示 | 悬停写明 Ctrl/⌘+. |
| 8 | 结果行数没有千分位（`12345 行`） | 与“已读 / 总数”统一用千分位 |

## 表格筛选条件

| # | 问题 | 处理 |
|---|---|---|
| 9 | **SQL 条件看不出输入框**：无外观的小号输入框，占位示例像一行说明文字，看起来没有地方可以输入 | 有边框的输入框，前面固定写 `WHERE`，等宽字体、正常字号；改了没应用时边框变强调色（`07`、`08`） |
| 10 | 条件和“应用条件 / 清除”分在两行，动作被推到窗口最右边，中间一大片空白 | 写法切换、条件、动作排在一行；动作紧贴条件区，窄窗口里整行换行 |
| 11 | 未应用只有一个 6px 圆点；“应用”在没有改动时退成一个只有对勾的图标；清除是一个 ×，容易被当成“关闭筛选栏” | 未应用写成“未应用”小标签；“应用条件”始终写字（有改动时是主按钮）；清除写成“清除” |
| 12 | “添加条件”是窗口最右边的一个 + 图标 | 跟在最后一个条件后面，带文字（`06`） |
| 13 | 悬停写法切换时弹出一长句说明，挡住表格 | 说明只挂在漏斗图标上 |

## 验证

- 原生应用（PostgreSQL 16）：空状态、选区切换按钮文字、`Ctrl+Alt+Enter` 运行全部、执行中切到正在跑和排队的语句、执行结束都看过截图。
- 新增测试：`caret_counts_lines_and_characters_not_bytes`、`the_status_line_follows_the_cursor_and_selection`（GPUI 真实绘制）、
  `statement_progress_marks_only_the_first_unfinished_statement_as_running`、`running_time_reads_in_tenths_then_minutes`、
  `the_run_button_names_what_it_will_run`（GPUI 真实绘制：按钮文字随选区变化、工具条上有“运行全部”、空结果页列出执行方式）。
- `filter_strip_keeps_rows_errors_and_actions_inside_three_widths` 增加断言：SQL 条件框高度不低于 26px，三档宽度下动作不越界，且同一行时紧贴输入框（间距 ≤ 12px）。
- `cargo test --manifest-path src-tauri/Cargo.toml --locked`：1239 passed，1 failed，9 ignored。失败的是 `live_engines_compare_a_made_difference_and_read_the_diagram`：本机没有起 SQL Server 夹具（Connection refused）；同一测试里 PostgreSQL / MySQL / MariaDB 都通过。
- `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --locked`：0 告警。

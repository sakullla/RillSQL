# 设计：RillSQL 桌面级 UI/UX 重做

- 日期：2026-10-17
- 状态：五段设计评审已通过
- 前置文档：`docs/requirements/2026-10-16-使用体验重做.md`（R1–R11）。本设计**不修改**其中任何行为需求，只重做呈现与交互。
- 推进方式：底座优先（先控件与交互原语 → 再外壳骨架 → 最后逐屏套用）。

## [S1] 问题

使用者反馈三条，本设计逐条对应：

1. **使用体验太差** —— 页面像网页后台而不是工具：24px 大标题、大卡片、胶囊按钮、大量留白、原生 `<select>`、按钮以文字为主。
2. **不太像桌面 GUI 管理工具** —— 缺少菜单栏、图标化工具栏、状态栏分段、密集树与网格这些桌面工具的骨架。
3. **操作与鼠标体验烂** —— 右键几乎不可用、hover/按压/焦点反馈弱、不能拖（分隔条/列宽）、表格只能单选单击、双击没有统一语义、滚动与点击区域混乱。

现状取证（重做前）：

- CSS 类使用频次：`.btn` 122 处、`.sm` 96 处、`.icon-btn` 仅 8 处；图标仅 19 个。
- 样式总量约 1700 行（`base 326 / shell 323 / workbench 184 / structure 194 / connections 165 / grid 235 / tokens 195 / catalog 74`）。
- 右键菜单只存在于对象树（`ExplorerTree.vue`）与标签栏（`WorkspaceView.vue`）。
- 可拖分隔条只有侧栏宽度（`Sidebar.vue`）与编辑器/结果高度（`QueryTab.vue`）；**没有列宽拖拽**。
- 网格是"单击选中单个单元格、双击编辑"（`DataGrid.vue` / `QueryResultGrid.vue`），**没有行/列多选、没有拖选、没有 Ctrl+C 出 TSV**。
- 设置页与连接页、历史页筛选器全部使用原生 `<select>`。

## [S2] 目标与成功标准

目标：把 RillSQL 的观感与手感做到**桌面数据库管理工具**水准，同时完整守住 R1–R11 的既有验收。

可测的成功标准：

1. 页面级标题不超过 16px，工作屏不出现大标题与卡片式宣传层。
2. 默认密度为紧凑：行 26px / 树 23px / 控件 26px（现为 32 / 30 / 34），设置中仍可切回标准。
3. 六个位置具备贴合场景的右键菜单：对象树、结果/表数据网格、标签栏、SQL 编辑器、连接列表行、历史条目。
4. 网格支持拖选、Shift 连选、Ctrl 加选、Ctrl+A 全选、Ctrl+C 复制为 TSV、方向键移动、Enter 编辑、Esc 取消。
5. 列宽可拖拽，双击列边界自适应内容宽度。
6. 全部控件具备 hover / active / focus-visible / disabled 四态，焦点环 2px 且在浅深色下均可见。
7. 1360×900、900×900、640×900 三档宽度下页面本身无横向滚动条（R6 不回退）。
8. `npm run typecheck`、`npm test`、`npm run verify:workbench`、`npm run capture:ui` 全绿。
9. 浅色与深色是两套分别打磨的配色，不是机械反色。
10. R1–R9 的全部既有验收用例继续通过。

## [S3] 不做事项

- **不引入组件库或新的运行时依赖**（底座全自研）。
- 不新增引擎、AI、ER 图、云账号、同步或遥测（R10）。
- 不放宽凭据库、TLS 主机名校验与未执行 SQL 的草稿边界（R11）。
- **不做标签拖拽排序**（本轮明确排除；关闭/关闭其他/关闭右侧仍要做）。
- 不做 Excel 式单元格填充拖拽（数据库写入必须走预览确认，R7 不变）。
- 不改数据读取、分页、写入预览、导入导出的行为逻辑，只改呈现。
- 不改快捷键的既有语义，只做增补与在菜单中展示。

## [S4] 设计语言

### S4.1 排版

- 字号刻度收敛为 5 档：`11 / 12 / 13 / 15 / 18` px（替代现 11.5 / 12.5 / 13.5 / 16 / 20 / 24）。默认 UI 字号 12px。
- 面板标题 15–16px、600 字重；分区标签 11px、700 字重、`letter-spacing .06em`、大写（英文）或加粗（中文）。
- 中文 UI 沿用现有系统字体栈（`--font` 不变）；SQL、数据、路径、耗时一律等宽（`--mono`）。
- 所有表格与状态栏数字启用 `font-variant-numeric: tabular-nums`。
- 行高：单行控件 1.0、正文 1.45、编辑器代码行高 20px（字号由现有 `--editor-font` 设置控制，默认 12px）。

### S4.2 形状与线条

- 圆角：控件 4px、面板/浮层 6px、状态标签 3px。**取消胶囊圆角**。
- 面板之间只用 1px 发丝线分隔，不靠阴影制造层次；面板本身无投影。
- 阴影只用于浮层，三档：`sm 0 1px 2px`（内嵌浮出）、`md 0 14px 34px + 0 2px 6px`（菜单）、`lg 0 24px 60px`（对话框）。

### S4.3 颜色（浅色）

| --- | --- | --- |
| 应用底 | `--bg` | `#eef0f2` |
| 标题栏/工具栏 | `--chrome` | `#f4f5f7` |
| 面板 | `--panel` | `#ffffff` |
| 次级面板/侧栏 | `--panel-2` | `#f7f8fa` |
| 凹陷（行号列、空态） | `--sunken` | `#f7f8fa` |
| 悬停 | `--hover` | `#eceff3` |
| 按下 | `--active` | `#e3e8ee` |
| 正文 / 次要 / 弱 | `--text` `--text-2` `--text-3` | `#1b2229` `#5a6672` `#8794a1` |
| 发丝线 / 强线 | `--line` `--line-2` | `#dfe3e8` `#c4ccd4` |
| 强调 | `--accent` | `#0f766e` |
| 强调悬停 / 按下 | `--accent-hover` `--accent-active` | `#0b5f59` `#094f4a` |
| 强调浅底（实底） | `--accent-soft` `--accent-text` | `#e6f2f0` `#0b5f59` |

### S4.4 颜色（深色）

深色**单独设计**，不是反色：底 `#0f1519`、chrome `#121b20`、panel `#161f25`、panel-2 `#1a242b`、线 `#26313a`、正文 `#dfe7ec`、次级 `#9fb0bb`、弱 `#7b8b96`；强调 `#2dd4bf`（hover `#5eead4`），选中底 `rgba(45,212,191,.14)`。状态/环境/引擎色各自取更亮一档以保证在深底上的对比度不低于 4.5:1。

### S4.5 动效

时长沿用 `--dur-fast 120 / --dur 180 / --dur-slow 280` 与 `--ease`；新增规则：浮层用 `opacity + translateY(4px)` 入场，控件状态变化只用背景与边框过渡，**不做缩放**；`prefers-reduced-motion` 下全部归零（已有逻辑保留）。

## [S5] 桌面底座（控件层）

### S5.1 落地原则

全自研，不引入 headless 库、不引入新运行时依赖。新增目录 `src/ui/`，只放可复用控件与浮层，不放业务；业务模块通过 `src/ui` 导入。现有 `.btn`（122 处）与 `.icon-btn`（8 处）由 `src/ui` 的实现接管，**原 class 名在本轮全部保留为别名**，调用点不迁移、不重命名（调用点收敛不属于本设计范围）。

### S5.2 控件清单

| 控件 | 关键点 |
| --- | --- |
| `Button` | 主 / 次 / 幽灵 / 危险 四种 `variant`，`sm`（24px）与 `md`（26px）两档，可带左侧图标与右侧 `kbd` 提示 |
| `IconButton` | 26×26，必须带 `title` 与 `aria-label`，hover 出底色 |
| `TextInput` / `SearchInput` | 26px 高，`focus-within` 出强调边框与 2px 光环 |
| `Listbox`（**替换全部原生 `<select>`**） | 触发器 + 浮层；支持分组、可选筛选、方向键/Home/End/Enter/Esc、`aria-activedescendant`、外点关闭、窗口边缘翻转 |
| `Checkbox` / `Switch` | 设置页与筛选器使用 |
| `Segmented` | 密度（紧凑/标准）、主题等二到三项切换 |
| `Tag` | 环境（开发/测试/生产/本地）、状态（已连接/未连接/失败）、引擎徽标；3px 圆角 |
| `Menu` / `ContextMenu` | 统一浮层实现：`role="menu"`、方向键导航、快捷键右对齐、分组分隔线、危险项、禁用项、子菜单延时展开 |
| `Tooltip` | 悬停 400ms 出现，承载图标按钮的说明与快捷键 |
| `Toast` | 操作结果反馈，右下角堆叠，可手动关闭 |
| `Dialog` | 现有 `modal` 结构统一化，焦点陷阱 + Esc 关闭 + 初始焦点落在安全按钮 |
| `Toolbar` / `Tabs` / `Splitter` / `TreeRow` / `EmptyState` | 结构件，见 S6、S7 |

### S5.3 四态与光标

- `hover`：背景从 `--panel` → `--hover`，边框 → `--line-2`。
- `active`：背景 → `--active`，`box-shadow: inset 0 1px 2px`，`transform: translateY(.5px)`。
- `focus-visible`：`outline: 2px solid var(--accent); outline-offset: 1px`（不依赖 box-shadow，保证深色下可见）。
- `disabled`：`opacity .55`、`cursor: not-allowed`、去掉 hover/active 反馈。
- 光标规范：可拖边 `col-resize` / `row-resize`；可拖动占位 `grab`/`grabbing`；禁用 `not-allowed`；单元格编辑 `text`；文本选择 `default`（网格内不全局禁用选中，见 S6.4）。

### S5.4 图标

从 19 个扩充到不少于 50 个，统一：`viewBox 0 0 24 24`、`stroke-width 1.7`、圆头圆角、`fill: none`（少数实心例外）。命名沿用 `src/shell/icons.ts` 的注册方式。

### S5.5 浮层层级

统一为 5 档，禁止各页面自行写 z-index：`base 0 / sticky 10 / float 100 / menu 200 / dialog 300 / toast 400`。

### S5.6 无障碍基线

- 所有交互控件可 Tab 到达，浮层内焦点陷阱，关闭后焦点回到触发元素。
- 树保持 `role="tree"` / `aria-expanded` / `aria-selected`；标签条保持 `role="tablist"`；网格用 `role="grid"` + `aria-selected`，选中区域用 `aria-activedescendant` 表达。
- 每个右键菜单项都有等价快捷键或命令面板入口（保证纯键盘可用）。
- 颜色不作为唯一信息载体（R6）：环境文字、成功/失败文字始终出现。

## [S6] 交互模型

### S6.1 右键菜单矩阵

| 位置 | 菜单项 |
| --- | --- |
| 对象树节点 | 打开表数据、打开表结构、新建查询到此对象、复制限定名、生成 SELECT、在新标签打开；连接节点额外有 连接/断开、编辑、测试、复制、删除 |
| 结果/表数据网格（行、列、单元格三套上下文） | 复制值 / 复制行 / 复制列（TSV）、按此值筛选、生成 SELECT / UPDATE、跳转并定位行、编辑单元格、标记删除行；只读结果时禁用写入项并说明原因 |
| 标签栏 | 关闭、关闭其他、关闭右侧、全部关闭、复制 SQL、固定/取消固定 |
| SQL 编辑器 | 执行选区/光标语句、格式化、执行计划、复制、命令面板、清除 |
| 连接列表行 | 连接/打开、编辑、测试连接、复制配置、在工作区打开、删除 |
| 历史条目 | 载入编辑器（不执行）、复制 SQL、查看执行详情、按连接筛选 |

菜单统一：`Esc` 关闭、外点关闭、滚出视口自动翻转、危险项红色并需二次确认入口。

### S6.2 拖拽

- 侧栏宽度：200–480px，拖动时出现 2px 强调色指示线，双击把手复位为 234px。
- 编辑器/结果分隔：20%–70%（沿用现有 `query-splitter`，把手视觉增强为 6px + 中央握槽，hover 变色）。
- **列宽**：表头右边界 `col-resize`，最小 48px，双击自适应内容宽度；拖动中显示宽度提示。
- 不做：标签拖动排序、单元格填充拖拽。

### S6.3 选择与编辑

- 单击单元格 = 选中该单元格并定位到行；单击行号 = 选中整行；单击表头 = 选中整列。
- `Shift+单击` = 从锚点连选（矩形区域）；`Ctrl/Cmd+单击` = 加选/减选；`Ctrl+A` = 全选已读取行。
- 拖拽 = 矩形拖选；`Shift+方向键` 扩展选择，`方向键` 移动焦点。
- `Enter` 编辑当前单元格、`F2` 同义、`Esc` 取消编辑与选择、`Tab`/`Shift+Tab` 横向移动。
- `Ctrl+C`：单格复制值、多格复制 TSV（含表头，可由设置切换）。
- 双击：单元格进入编辑、树节点打开对象、列边界自适应列宽。
- 未提交的修改仍走现有暂存 + 预览确认（R4/R7 不变），被拒绝的单元格保持可见错误标记。

### S6.4 滚动

- 滚轮按**悬停区域**决定滚动目标（树、编辑器、网格、页面各自响应），不发生"看着在网格里滚、实际页面在滚"。
- `Shift+滚轮` 横向滚动网格；网格横向滚动只发生在 `.grid-scroll` 内部。
- 网格表头与行号列在纵向/横向滚动时均钉住（现有 sticky 基础上补行号列 sticky）。
- 页面本身在 1360/900/640 三档宽度下永不出现横向滚动条（R6）。

### S6.5 键盘（增补项）

沿用 `shortcuts.ts` 全部既有快捷键，新增/明确：网格 `Ctrl+C`（TSV）、`Ctrl+A`、`Enter`/`F2`/`Esc`、`Ctrl+F` 网格内查找、`F4` 打开结构、`Alt+↑/↓` 在树中移动。所有新增项进入 `ShortcutHelp`。

## [S7] 外壳与工作台布局

### S7.1 顶部（菜单栏常驻）

- 第 1 行 **菜单栏 26px**：`文件 / 编辑 / 视图 / 查询 / 工具 / 窗口 / 帮助`，右端为连接指示（点 + 连接名/库名）、主题切换、窗口控制按钮。菜单项内展示对应快捷键。Tauri 自定义标题栏下，菜单栏空白区承担窗口拖动，菜单按钮与窗口按钮不参与拖动（沿用 `data-tauri-drag-region` 现有约定）。
- 第 2 行 **工具栏 36px**：`新建 · 打开 · 保存 ‖ 格式化 · 执行计划 · 历史 ‖ 命令搜索（居中，宽 300px）‖ 导出 · 执行`。图标按钮优先，带 `title` 与 tooltip；`执行` 为唯一实心强调按钮并内嵌 `Ctrl Enter` 键帽。

### S7.2 主体尺寸

| 部件 | 尺寸 |
| --- | --- |
| 活动栏 | 44px（保留现有深色底、激活左侧 2px 指示条、hover 出底色） |
| 侧栏 | 默认 234px，可拖 200–480px，`Ctrl+B` 收起 |
| 标签条 | 30px，矩形标签 + 顶部 2px 强调线表示激活，`✕` 悬停显示，脏标签显示 `●` |
| 目标条 | 32px，连接/库选择器 + 连接状态 + 环境标签 + 已读取进度 + 取消 |
| 编辑器 | 剩余空间，38px 行号栏 + CodeMirror |
| 编辑器提示条 | 24px，快捷键提示 + 引擎 |
| 结果头 | 30px，分区标签 + 行数/耗时 + 图标动作（查找/排序/筛选 ‖ 删除行/导出） |
| 网格行 | 紧凑 26px / 标准 32px；表头 26px；行号列 40px |
| 状态栏 | 24px，分段可点击：点连接名跳连接页、点行数触发排序、点光标位置无动作 |

### S7.3 断点

- `≤960px`：侧栏默认收起（现有逻辑保留）。
- `≤640px`：活动栏压缩为 40px 图标列，侧栏以抽屉形式覆盖内容区，可开关；守 R6 的 640×900 验收。

### S7.4 快捷键与菜单对齐

菜单项文案与 `shortcuts.ts` 一一对应；`ShortcutHelp` 面板按菜单分组重排，保证"菜单里能看到的 = 快捷键表里能查到的 = 命令面板里能搜到的"。

## [S8] 次级页面

### S8.1 连接页

- 去掉 24px 大标题与"卡片式统计头"，改为工具窗口式：`16px 标题行` + 紧凑工具栏（新建连接 / 打开 SQLite / 导入配置）+ 一行筛选（搜索、引擎 Listbox、环境 Listbox、计数）。
- 列表由宽卡片表格改为**密集行式列表**：引擎徽标 / 名称 + 环境标签 / 地址 + 库名 / 传输与认证 / 状态 / 操作图标组。
- 双击行 = 连接并进入工作区；右键行出菜单（S6.1）；`…` 溢出菜单保留编辑/复制/删除。
- 底部保留一行凭据说明（R1 文案要求）。

### S8.2 历史页与保存的查询

- 左列表右预览结构保留；列表改为密集行：状态标记 / 连接·库 / SQL 首行 / 耗时 / 时间，按日期分组保持。
- 预览面板可拖宽（280–520px），SQL 预览用等宽 + 行号。
- `载入编辑器` 为主按钮（不执行，R5 不变），右键条目出菜单。

### S8.3 设置页

- 由"顶部小按钮跳转 + 长表单"改为**左侧分区导航（外观与编辑器 / 数据读取 / 本地数据）+ 右侧分组表单**，右侧滚动、导航高亮当前分区。
- 所有原生 `<select>` 换成 `Listbox`；开关换成 `Switch`；密度与主题用 `Segmented` 与现有主题预览缩略图（保留）。
- 修改立即生效、只存本机（R5 不变）。

### S8.4 结构页

- 表名 + 连接 + 字段/索引数量摘要行，其下 `字段 / 索引 / 外键 / 危险操作` 四个页签。
- 字段与索引表格复用结果网格的表头、行高、列宽与右键规范。
- 结构变更确认面沿用 R7（显示连接名、对象名、环境文字）。

### S8.5 空态与错误态

统一 `EmptyState`：16px 图标 + 一行说明（发生了什么）+ 一行次要说明（为什么）+ 一个主按钮（下一步）。适用：无连接、连接失败、对象读取失败（带重试）、查询失败（带原因与可编辑提示）、表无行、筛选无命中（带清除筛选）。**"无行"与"无命中"文案必须不同**（R9）。

### S8.6 欢迎区

无连接时保留两个入口（新建连接 / 打开 SQLite）与本机凭据说明，但由大卡片改为紧凑列表项 + `EmptyState` 排版，页面主标题不超过 16px（R1：不出现宣传口号）。

## [S9] 主题 · 密度 · 响应式 · 无障碍
